# The Local Table — Responsive Restaurant Demo

This version is hardened for:
- Mobile phones: 320px+
- Tablet portrait/landscape
- Small laptops
- Desktop
- Large desktop displays
- Mobile landscape

Included:
- Responsive navigation / hamburger menu
- Responsive hero and restaurant images
- Responsive food/menu cards
- Responsive offer, about, location and CTA sections
- Responsive testimonials and footer
- Touch-friendly buttons
- Floating WhatsApp button
- WhatsApp ordering for every menu item
- Book a Table WhatsApp links
- Weekend offer WhatsApp link
- General enquiry WhatsApp link
- Menu category filtering
- Scroll reveal
- Active navigation
- Reading progress bar
- Reduced-motion accessibility support

## Change WhatsApp number
In `script.js`:
const WHATSAPP_NUMBER = "919876543210";

Use country code + number without +, spaces or brackets.

## Run
Open `index.html` directly or use VS Code Live Server.
